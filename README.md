# Personal Portfolio Website

## Project description

A responsive personal portfolio website for Kanishka Jangid. It introduces the student, shares education and skills, and presents five project entries for a college assessment.

## Technologies

- HTML
- CSS
- JavaScript

## Features

- About Me section
- Education details
- Skills with beginner-friendly labels
- Five project cards
- Project search
- Light and dark mode toggle
- Responsive layout for mobile and desktop

## Run locally

1. Download or clone this project to your computer.
2. Open the project folder.
3. Double-click `index.html` (or right-click it and choose a browser) to view the website.

No install or build step is needed.
